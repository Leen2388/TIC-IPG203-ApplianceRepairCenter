نظام إدارة مركز صيانة الأجهزة المنزلية
TIC_IPG203_F25
التشغيل:
يتطلب .NET 8 SDK أو إصداراً أحدث يدعم بناء net8.0.
افتح ApplianceRepairCenter.sln في Visual Studio مع دعم .NET 8، أو من هذا المجلد:
dotnet build ApplianceRepairCenter.sln
dotnet run --project ApplianceRepairCenter.csproj
مثال جاهز:
dotnet run --project ApplianceRepairCenter.csproj -- --demo
فحوص التحقق:
dotnet run --project ApplianceRepairCenter.csproj -- --self-test
استخدام القائمة:
1 إضافة جهاز من أحد الأنواع الثلاثة، ثم إدخال بياناته وتواريخه.
2 بدء الصيانة باستخدام الرقم التسلسلي.
3 تسجيل وصف العمل وأجرة اليد والقطع.
4 إنهاء الإصلاح وإطلاق إشعار الجاهزية.
5 تسليم الجهاز بعد إصلاحه.
6 عرض الأجهزة، 7 تصفية الحالة، 8 عرض المجموع والعداد.
التواريخ yyyy-MM-dd، والكسور العشرية بنقطة مثل 25.50.
القائمة بالإنكليزية لتسهيل عرضها في الطرفيات المختلفة.
حدود المشروع:
البيانات في الذاكرة وتختفي عند إغلاق البرنامج. لا توجد قاعدة بيانات أو إرسال رسائل حقيقي.
الأسعار تعليمية بوحدة نقدية افتراضية: غاز الثلاجة 40، خدمة الحوض 25، التنظيف العميق 30.
المجموع يجمع التكاليف المسجلة لكل الأجهزة، بما فيها التي ما زالت قيد الصيانة؛ ليس تقرير إيرادات مقبوضة.
RepairedCount عداد تراكمي خلال تشغيل البرنامج يشمل الأجهزة المسلمة، وليس عدد الأجهزة الجاهزة الآن.
