نظام صيانة الأجهزة المنزلية
وظيفة مقرر TIC_IPG203_F25

البرنامج مكتوب بلغة C#، ويعمل من خلال قائمة Console. فيه ثلاثة أنواع من الأجهزة: ثلاجة وغسالة ومكيف. يمكن إضافة جهاز، وتسجيل شغل الصيانة وتكلفته، ثم إنهاء الإصلاح وتسليم الجهاز لصاحبه.

التشغيل
المشروع يحتاج .NET 8 SDK. يمكن فتح ApplianceRepairCenter.sln من Visual Studio، أو تشغيل الأوامر التالية من مجلد المشروع:

dotnet build ApplianceRepairCenter.sln
dotnet run --project ApplianceRepairCenter.csproj

من القائمة نضيف الجهاز أولاً، ثم نبدأ الصيانة ونسجل وصف الشغل وأجرة اليد وثمن القطع. بعد ذلك يمكن إنهاء الإصلاح وتسليم الجهاز. يوجد أيضاً عرض لجميع الأجهزة، وبحث حسب الحالة، وعرض مجموع التكاليف.
التاريخ يكتب بالشكل yyyy-MM-dd، والعدد العشري مثل 25.50.

مثال للتجربة
dotnet run --project ApplianceRepairCenter.csproj -- --demo

المثال فيه ثلاثة أجهزة. مجموع تكاليفها 340، وفي نهايته تكون الثلاجة جاهزة للتسليم، والغسالة قيد الصيانة، والمكيف مسلماً لصاحبه.

الفحوص
dotnet run --project ApplianceRepairCenter.csproj -- --self-test

توجد 29 حالة في SelfTests.cs لفحص الحسابات والمدخلات وتغيير الحالة. نتائج التشغيل موجودة في Verification.txt.

ملاحظات على البرنامج
البيانات تبقى أثناء التشغيل فقط، وتضيع عند إغلاقه. إشعار انتهاء الإصلاح يظهر على الشاشة.
أضفنا تكلفة ثابتة لبعض الخدمات: 40 لخدمة غاز الثلاجة، و25 لخدمة حوض الغسالة، و30 للتنظيف العميق للمكيف. هذه أرقام وضعناها للمثال، وتضاف إلى أجرة اليد والقطع.
مجموع التكاليف يشمل كل الأجهزة التي سجلت لها تكلفة، حتى لو لم ينته إصلاحها. أما RepairedCount فيحسب الإصلاحات المكتملة خلال التشغيل، ويشمل الجهاز بعد تسليمه أيضاً.

الملفات
Contracts: واجهة IRepairable.
Models: بيانات الجهاز والأنواع الثلاثة وحالات الصيانة.
Services: قائمة أجهزة المركز والبحث والحساب.
Events: التفويض المستخدم عند تغير حالة الجهاز.
Utilities: التحقق من المدخلات.
Report.html: شرح المشروع ومخطط الفئات.
UML.svg: نسخة منفصلة من المخطط.
